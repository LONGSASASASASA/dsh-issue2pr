问题现在的行为
01 / 打开方式全部产物、阶段文件、补丁、证据、复核历史统一文件弹窗，点击即定位；取消展开整页，原阶段正文保持挂载。

03 / 大文件阶段事件、P8 输出、P6 文本回退由 useLogArtifact 按文件大小读取尾部；读取失败入口保留，同轮刷新失败保留已读内容。切任务、重跑、删除和截短文件时清除旧快照。
04 / 搜索搜索长日志时补读全量，阶段事件仍按当前阶段过滤；提示实际范围及失败。搜索与筛选结果每页 50 条，复制下载不受关键词筛选影响。Agent 搜索范围是时间线镜像，P8 搜索测试输出，原始日志仍通过文件入口查看。全量读取保留服务端 5MB 上限。
05 / 阅读操作执行中和已结束均默认最近 5 条事件 / 5 行文本，新记录只更新窗口，不带动整页滚动。查看详情时冻结阅读现场并提示新增；专注查看历史每页 50 条、从末页起读。阶段事件弹窗默认五行，点击“查看历史”在同一弹窗内展开。
06 / 执行方式非 P6 委托也按实际标记与启动快照显示“外部会话 · 过程未采集”，不冒充宿主模型执行。长日志尾部不用于推算整个阶段耗时。
07 / 计数页签显示“补丁 N”；预览内单列该补丁涉及的源码文件数。
08 / 入口名称标题旁“阶段事件”按钮打开当前阶段的平台日志弹窗；打开文件叫“打开源文件”，切模式叫“原文/排版”，ACCEPT 跳汇总叫“查看汇总”。

新增修复：事件详情中的“原始 JSON”

原来打开的是已精简的时间线文本，字段不完整。现在新执行将 Agent 实际返回的每条消息单独保留，事件摘要通过确定的来源位置和校验值定位原文。同一消息有多个内容块时，共用这份完整 JSON；工具结果按同次执行的真实工具标识关联，原始内容不掺入平台摘要字段。

详情可以读完整正文、工具参数和结果；“原始 JSON”支持折叠、搜索全部字段、复制完整消息。关联结果单独切换，源文件仍在同一层弹窗打开。列表仍默认最近 5 条，列表搜索查摘要文件，JSON 搜索查当前消息全部字段。

历史数据只有在已有原始日志能唯一匹配时才显示 JSON。未保存、无法唯一关联或属于平台事件，会明确提示，不补造字段。DSH 仍在执行结束后提供记录；单条原始消息读取上限为 5MB。

最新验证：UI 85 项、全量 364 项测试通过；5 组采集器、只读接口和页面组件的隔离浏览器联调通过，另 7 组最近五条策略回归通过，覆盖字段保真、关联结果、搜索复制、弹窗返回、历史缺失及窄屏深色。记录见 落地实施计划第⑨至⑪批、变更记录。正式 DSH 登录态和真实任务连续执行仍需宿主验收；本次未运行真实 Agent 或修改历史产物。
