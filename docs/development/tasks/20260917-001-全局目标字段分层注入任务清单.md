## 目标

本轮解决 P1 产出的目标契约(success_criteria / constraints)只在 P2 和 P11 被直接消费、P3-P9 全靠上游转述导致的**目标漂移**,同时避免无防护注入 goal 给执行层带来的**扩权**。

交付标准:**goal 由 P1 单一来源产出,P2 起只读、机械投影、无二次 LLM 加工;决策层(P3/P4/P5/P6·planner)与审查层(P9 之前的委外链路)注入完整投影,执行层(P6·coder builtin)只注入一句背景;边界声明由投影函数统一注入;投影条数与字符双重有界且截断显式标注;旧 run 无 goal 字段可兜底运行。**
