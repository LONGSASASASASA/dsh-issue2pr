- 以 [v9.html](../ui-prototype/v9.html) 的最终样式和已有截图为基准；比较插件内容区，不复制原型中的演示宿主侧栏和假数据。

## 差异原因与修复

原实现主要迁移了功能入口和颜色变量，旧组件尺寸、通用表单规则与追加样式仍共同决定布局。任务详情默认展开流程和侧栏、规划以通用字段表展示、执行输出层级重复，也改变了 v9 的空间分配。仅保留相同配色无法还原页面。

本轮统一工作台作用域样式，修复筛选宽度与代码预览配色，恢复项目卡片、整行任务、紧凑阶段布局、规划依赖列表、实例概览和宽幅终端。文件按真实阶段与明确的实例关系分组，支持独立滚动及返回现场；补充非默认产物文件名、短补丁路径和同节点多文件执行记录的映射。

复核只面向当前阶段汇总。任务级检查分开显示报告结论与阶段状态，避免“阶段已复核”让失败报告看似通过。清理无引用的旧导航状态、组件、工具函数、重复样式及助手悬浮入口；保留原有真实助手、执行器、凭据和流水线接口。
