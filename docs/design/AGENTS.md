# 设计文档协作约束

本文件补充项目根目录的 AGENTS.md，约束本目录的设计文档及基于文档开展的实施工作。

## 1. 文档简介

主文档 [issue2pr-studio.html](./issue2pr-studio.html) 是 Issue2PR Studio 的产品与工程设计规格书，
描述从需求或 Issue 到可验收 PR 交付的产品目标、系统架构、流程、证据与工程契约。

## 2. 长期规划与用户决定权

- 主文档描述长期最终规划，不代表当前已实现能力，也不构成整份规划的实施授权。
- 只有用户明确指定实施某个点，才开始该点的实施规划与开发；未明确要求时，不擅自实现产品功能。
- 文档讨论、评审或修改不等于授权开发其中描述的功能。
- 若用户指令偏离主文档，且文档方案更合理，应及时汇报偏差、理由和影响。
  最终采用哪个方案由用户决定，不得自行替用户改选方案。

## 3. 基于当前代码逐点演进

- 用户明确实施点后，先检查现有实现、调用关系与约束，再在指定范围内规划改动。
- 参考主文档目标，结合当前项目代码做适配；必要时提出更合理、兼容现有项目的局部改进方案。
- 按用户明确指定的点逐步实施，不一次性实现全部规划，不擅自扩大范围或进行整体重构。
